## What I'm building

- **Agent tooling** —— 给 Claude Code / Codex / dsh 写插件与挂载层，让模型能看图、能读屏、能在后台安静跑着。
- **Desktop shells** —— Rust + Tauri / egui 的本地优先桌面端。双击即用，不要求用户先自备一套运行时。
- **Automation** —— 浏览器自动化那一侧，连同配套的数据隔离与离线演练环境。
